## Read first

Ruling doc; `object_contract` + `object_inventory` MCP output (machine
truth); `conversion-playbook.md`; `02-architecture-and-schema.md`;
`03-mapping-and-agent-contract.md`.

## Context

The platform site's reader-facing content is a user instruction manual —
Wolf's window into how the system works and his design surface for
improvements. It is authored AS GOVERNED OBJECTS on the platform site via
MCP: the manual is produced by the workflow it documents (the strongest
possible proof the workflow works).

## Scope

- One reference page per governed type (all ten: page, section,
  navigation, taxonomy, site, template, content_item, section_template,
  theme, product): what it is, what it can be used as, attributes,
  permitted actions/patch ops, lifecycle, a worked example.
- Plus: lifecycle overview (checkout→patch→validate→review→publish→
  release), roles/permissions explainer, genesis page (the CLI + runbook,
  per R6), agent-credential page (T11.10 mechanism).
- **Drift-guard**: a test comparing each reference page's documented
  action list against live `object_contract` output — the manual cannot
  silently go stale.
- Content plain-spoken, written for Wolf, not for developers.

## Non-goals

No new object types; no admin-UI work; no styling project (default theme
is fine).

## Acceptance criteria

- All manual pages live on the platform site, created via MCP,
  drift-guard test green. Committed `T14.5: …` (content commits ride the
  normal publish path); no PR.
