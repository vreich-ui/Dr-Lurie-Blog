`docs/cms-architecture/12-object-tracking-and-analytics.md` §5.1 + §6 (normative), `src/lib/renderer/section-annotations.ts` + `src/lib/article-object/render-nodes.ts` + `src/layouts/PageLayout.astro` (the `data-cms-*` attributes the loader rides), `src/components/common/NetlifyOptInCapture.astro` + `src/pages/shop/[slug].astro` (sendBeacon precedent), `src/layouts/Layout.astro` (`<ClientRouter>` — View Transitions lifecycle).

## Context

The collection client: pageviews, section/node impressions + dwell, scroll depth, engagement time, delegated clicks, UTM/referrer — batched to `/api/t`. Cookieless by default (ZERO device storage; identity is computed server-side at ingest); a consented-upgrade hook is exposed but inert until T13.6 wires consent.

## Scope — files to create/modify

- NEW `src/lib/tracking/loader/` (TS modules; bundled via an Astro `<script>` import in T13.5 — this task ships the modules + unit tests, exercised through a thin test harness):
  - init from `#trk-config` JSON (project id, defaults matrix, goal map, batch/sampling knobs); hard bail on `/admin`.
  - pageview on `astro:page-load` ONLY (the double-fire guard); observers re-bind per page-load, flush + disconnect on `astro:before-swap`; module-scope listener registration (once).
  - ONE IntersectionObserver (threshold 0.5) over `[data-cms-section-id]`/`[data-cms-node-id]`; impression once per element per pageview; dwell = accumulated visible ms, reported on flush; skip `[data-cms-track="off"]` subtrees.
  - scroll-depth buckets 25/50/75/90/100 once each; visibility-aware engagement accumulator (no heartbeat).
  - one delegated click/auxclick listener: nav (`[data-cms-nav-object]`), section CTAs, product buy, outbound (foreign hostname), tag/term links; `trk:goal` CustomEvent consumption (the T13.7 bridge input).
  - read_progress/completion derivation for article pages (pct of public nodes seen; completion = last node impression).
  - UTM+referrer on session-first pageview only; queue + flush at `max_events`/`max_wait_ms` AND on `pagehide`/`visibilitychange→hidden`/`astro:before-swap`; `sendBeacon` with fetch-keepalive fallback; `sample_rate` on impressions/dwell only.
- Size-budget test: built loader chunk **≤4KB min+gzip (hard ceiling 6KB)** — build the harness entry and assert.
