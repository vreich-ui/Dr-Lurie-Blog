## Context

Every governed object gains an optional `tracking` body attribute (12-plan §2): `enabled?`, `label?`, `tags?`, `goals[]` with provider conversion mappings. One uniform op writes it everywhere because three types can't piggyback (`set_nav_meta` is hand-pinned strict; `taxonomy`/`section` have no body-fields op), and a one-writer funnel keeps the other seven fields ops out.
