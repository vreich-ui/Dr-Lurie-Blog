# T11.9 — Schema-migration harness: versioned migrations + fleet validation gate

**Phase 11 · depends_on: T11.8 · mode: notify · model: Fable · effort: high**
**Blocks:** T11.11.

## Read first

`src/schema/object-record-v1.ts` (`schema_version` per body; envelope), `docs/cms-architecture/02-architecture-and-schema.md` §3 (envelope invariants: `version` vs `content_revision` semantics), the additive-optional precedents (M-9 `columns`, `blueprintRef`, recipe metadata), `netlify/lib/object-validate.ts`, T11.8's matrix.

## Context

One site survives on additive-optional discipline; a fleet cannot: a core schema bump must be provably safe for EVERY client's store and exports before rollout, and breaking changes need an executable path, not a doctrine.

## Scope — files to create/modify

- ✚ `packages/core/server/migrations/` framework: a migration module per `schema_version` transition (`page.v1 → page.v2` shaped), pure `(body) → body`, with an inverse or an explicit `irreversible` flag; a registry mapping versions → chains.
- ✚ CLI `migrate-site.mjs`: `--site --dry-run` reports per-record disposition (parses-as-is / migratable / blocked); write mode applies via the STANDARD verb path (checkout → patch/replace → validate → publish is Wolf-gated per policy) — never raw blob writes.
- Fleet gate in CI (extends T11.8): on core PRs, every site's committed exports must parse under the head schemas OR the PR must carry the migration module + a green dry-run report per site; a failing site blocks merge.
- Adversarial tests: a synthetic v1→v2 with required-field addition — gate blocks without migration, passes with it; irreversible migrations demand an explicit human-visible marker.

## Deliver

A core schema change cannot merge unless every client provably survives it.

## Non-goals

- No actual schema bump shipped here. No store-side mass mutation (the CLI exists; running it against production is a per-migration, human-decided act).

## Acceptance criteria

- Framework + CLI + CI gate tested end-to-end on the synthetic case; full suite green; build-diff EMPTY.
- Committed `T11.9: …`; no PR.
